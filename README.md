# Mein Urlaubsplaner

Persönlicher Urlaubsplaner fürs iPad: Urlaubskonto mit Resturlaub, Gleitzeit, Vertretungen, NRW-Feiertage und Schulferien, wichtige Termine, Ausgabe für Excel und Kalender.

Adresse: https://kimkorkn.github.io/urlaubsplan/

Die App ist eine einzelne HTML-Seite ohne Server. Alle Einträge bleiben nur auf dem Gerät (im Speicher des Browsers bzw. der Home-Bildschirm-App). Dieses Repository enthält keine persönlichen Daten.

## Aufs iPad holen
1. Die Seite in **Safari** öffnen.
2. Teilen-Symbol → **Zum Home-Bildschirm**.
3. Die App vom Home-Bildschirm starten und dort einmal die Sicherung laden (Optionen → Datensicherung → Text einfügen → „Text laden“).

Bitte ab und zu unter Optionen eine Sicherung machen.
